Almost, but one small correction.

For binary `101`, from the back/right side:

```text
Place values: 4  2  1
Digits:       1  0  1
```

So it means:

```text
1 × 4 = 4
0 × 2 = 0
1 × 1 = 1
```

Then combine:

```text
4 + 0 + 1 = 5
```

So:

```text
101 binary = 5 decimal
```

Your wording:

> 1 ones, 2 zeros, 4 ones

is basically right, but say it like this:

```text
There is one 4, zero 2s, and one 1.
```

Important: you do **not** count like:

```text
1 + 0 + 0 + 1 + 1 + 1 + 1
```

Instead, you add the **place values where the digit is 1**:

```text
4 + 1 = 5
```

Another example:

```text
111 binary
```

Place values:

```text
4 2 1
1 1 1
```

So:

```text
4 + 2 + 1 = 7
```
